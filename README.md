# Victor Pamplona — Portfólio

Portfólio profissional de Victor Pamplona, desenvolvido em HTML, CSS e JavaScript.

## Estrutura

- `index.html` — página principal
- `marcelo-neto-advocacia.html` — case detalhado
- `assets/css/style.css` — estilos
- `assets/js/script.js` — interações
- `assets/images/projects/` — imagens dos projetos
- `assets/images/profile/` — foto profissional
- `assets/branding/` — logo e favicon

## Antes de publicar

Atualize o número do WhatsApp em `assets/js/script.js`:

```js
WHATSAPP_NUMBER: '55XXXXXXXXXXX'
```

Confirme também o e-mail e Instagram configurados nesse arquivo.
